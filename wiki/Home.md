# LEGO Manager

A personal web app for tracking the LEGO sets you own — add a set by number
and it pulls metadata, box art, and the official building-instructions PDF
automatically, so you can browse your collection and re-view any set's
instructions from the browser.

- **[Installation](Installation.md)** — Docker Compose setup, upgrading an
  existing deployment
- **[Configuration](Configuration.md)** — environment variables, Brickset
  API, authentication & single sign-on
- **[Security](Security.md)** — security posture and hardening notes
- **[Development](Development.md)** — contributing to the project (dev
  environment, project layout, testing, CI/CD)

See the [repository README](https://gitea.thehibbs.net/xamlok/lego_manager)
for a quick feature overview and the fastest path to getting the app running.
